# FINAL — One Adversarial Pass + Freeze

Run only after F0, S01–S12 and Q1–Q5 are closed.

## Required read set
- repository instructions;
- owner authorization;
- Master;
- design-system authority;
- execution ledger;
- surface packets only when a concrete final finding points to them;
- test policy.

Do not preload research archive.

## Mandatory pre-review gates

Run and record:
- `pnpm verify`
- `pnpm typecheck`
- full frontend unit suite
- production build
- `pnpm hardening:performance`
- default full native E2E phase set once
- complete required Light visual matrix at canonical maximized and governed minimum viewport
- representative Reduced Motion and minimal forced-colors regression when deterministic

A nondiagnostic infrastructure failure follows the repository's risk-based closure rule; it is not permission to change product behavior speculatively.

## Exactly one whole-app adversarial/coherence review

Review the implemented redesign against:
- all 109 canonical rows;
- Quiet Precision Atlas global laws;
- capability-vs-reference boundary;
- cross-screen hierarchy/coherence;
- keyboard/focus/a11y;
- geometry and overflow;
- performance/bundle;
- no invented capability;
- no regression to closed product invariants.

Materialize a **finite fixed finding set `F_final`** with severity, row IDs, files, violated authority, smallest safe correction and required rerun.

Do not conduct another discovery pass after `F_final` is frozen.

## Resolution

Fix:
- BLOCKER/HIGH/MEDIUM;
- LOW only when it directly violates explicit authority or is an obvious cheap defect.

Rerun only checks affected by those fixes, then rerun the mandatory final gates required by Master.
Do not run a second whole-app adversarial review.

## Freeze

When terminal predicate is true:
- persist final ledger;
- inspect full diff/history and repository status;
- ensure no uncommitted unintended files;
- create final scoped commit if needed;
- do not push; leave verified local commits for Product Owner review/publication;
- report exact commands, counts, artifacts, commits and any accepted nondiagnostic verification debt;
- STOP.
