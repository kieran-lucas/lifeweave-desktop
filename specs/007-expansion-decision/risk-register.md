# Slice 007 Risk Register

| Risk | Severity | Control |
|---|---|---|
| Subjective scores presented as objective truth | High | Publish weights, scores, uncertainty and honesty statement. |
| Large simulation count used as rhetorical proof | High | Explicitly call it sensitivity analysis only. |
| Search silently expands into AI/vector search | High | Explicit exclusions and local FTS5-only Task 18 boundary. |
| Search index becomes authority | Critical | Canonical tables remain authority; index is rebuildable. |
| Stale index after mutation | High | Same-transaction update or reliable dirty/rebuild protocol. |
| Vietnamese normalization loses meaning | High | Preserve original display text; test accented/unaccented and `đ/d`; document collisions. |
| Unsafe snippets/highlighting | High | Backend markers only; controlled escaped renderer. |
| Search duplicates navigation | Medium | Palette complements Today/Life navigation; does not replace them. |
| Outline duplicates Life tree | High | Defer generic Outline; later narrow to document headings. |
| Visual novelty overwhelms utility | High | Hold Visual Worlds for Product Owner. |
| Narrative schema locks too early | Critical | Defer production; require isolated schema A/B prototype. |
| Tags create classification burden | Medium | Defer until cross-cutting need is proven. |
| Backlinks/Graph built without relationship data | High | Require internal-link prerequisite. |
| Score distorts behavior | High | Defer formula; retain objective Analytics. |
| Prediction manipulates emphasis | High | Defer until calibration/control evidence. |
| Noteboard recreates Task cards | Critical | Keep deferred and enforce no Task-card invariant. |
| Agent implements Task 18 prematurely | Critical | Documentation-only diff gate. |
