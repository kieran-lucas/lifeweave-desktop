# 06 — Approved Exceptions and Non-Goals

These are deliberate exceptions, not unfinished convergence work.

## Light-only redesign
Light is the aesthetic acceptance target. Dark receives only low-cost catastrophic-regression protection; do not spend redesign effort polishing Dark.

## Narrative Visual Worlds
Paper, Sakura, Aurora and Nocturne may own authored-content palette/pattern semantics inside Narrative.
They are not permission to spread multi-color theming across operational chrome.

## Editorial font
Literata is the one approved self-hosted editorial family. Do not add another display/editorial font.

## Domain geometry
Life Edit, Life Graph, DnD transforms, graph/spatial coordinates, timeline/time geometry and similar domain layout may retain domain-specific geometry.
This exception does not permit private ordinary button/field/type/focus material.

## Reading measure
Basic Reader's disciplined ~768px reading measure is intentional.
Do not widen it for general “premium” feel.

## Narrative Studio width
Do not widen Studio merely because 768px looks suspicious in source.
Use the populated stress fixture. First fix composition. If density truly cannot work, Studio may graduate only to an existing shared frame, never a private width class.

## Page-width taxonomy
Only standard/wide/reading shared types.
Collapsed-sidebar asymmetry is not authority for a fourth width.

## Glass
Existing glass primitives may remain for genuine floating/transient layers.
Persistent workspace/content consumers should migrate toward semantic solid/tonal surfaces when touched.
Do not mechanically delete blur where it represents real depth.

## Optical exceptions
A documented optical exception is allowed when literal token placement is visibly worse, but the exception must be local, evidence-based and not create a parallel styling system.

## Native controls
Preserve native semantics when they are the actual product model.
TimeWheel remains hour/minute selects.
Do not replace native control semantics with decorative replicas just to match an image.

## Task deletion
Preserve current product behavior. Do not invent a new confirmation workflow or change domain semantics solely for redesign. Any bundle-sensitive enhancement outside canonical capability needs separate authority.

## Restore backup capture
Restore confirmation is real UI, but destructive completion must not be executed merely to obtain a visual artifact. Use deterministic safe fixture/preview behavior.

## Existing non-light accessibility modes
Forced colors and Reduced Motion are regression/safety modes. Do not use them as separate art directions.

## No new product scope
No profile/avatar, meetings panel, collaboration, cloud account, assistant widget, Calendar Day Details inspector, event system, Plan owner, or other capability absent from canonical source.
