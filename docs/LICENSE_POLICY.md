# License Policy

No open-source license has been selected.

Until the Product Owner explicitly chooses one:
- the repository should remain private;
- no file should claim MIT/Apache/GPL licensing for the project;
- third-party dependency licenses must still be audited;
- bundled fonts/icons/assets require explicit compatible licenses;
- generated setup placeholder icon is project-created and replaceable.

Public release requires:
1. project license decision;
2. dependency/license report;
3. attribution/NOTICE where required;
4. confirmation that personal/source materials are intended for publication.
