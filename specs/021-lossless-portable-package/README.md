# Slice 021 — Lossless Portable Package

Task 31 implements a bounded, single-document `.lifeweave.zip` interchange format for committed Basic Leaf and Narrative Canvas documents. Canonical JSON is authoritative; Markdown is a readable fallback; referenced images are privacy-sanitized, checksummed, and remapped on import to an empty active Life leaf.

This slice also closes the mounted-app local-midnight anchor debt. It does not export the Life tree, Tasks, drafts, history, settings, or a database backup, and it does not activate Task 32.
