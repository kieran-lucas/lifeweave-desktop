# Spec 014 — Narrative Multi-Scene Composition

Task 24 activates multi-scene Narrative Canvas. The single-scene constraint (`scenes.length === 1`) is relaxed to allow 1–20 scenes. Scene management is exposed in the Studio via a tab panel with add, delete, rename, and reorder operations.
