# Monochrome icon source

The Windows application icon is generated from `assets/brand/lifeweave-app-icon.svg`.
The shell mark is a transparent monochrome woven-W motif. The packaged icon places its two
intersecting paths on the Lifeweave blue-violet rounded-square field for a reliable silhouette at
small desktop sizes.

Regenerate the PNG/ICO bundle from the SVG source whenever the mark changes.
