# Lifeweave production screenshots

This folder contains 53 current light-theme screenshots from one real, maximized Windows
Tauri/WebView2 production walk.

The numbered filenames follow the interaction order. They cover the shell and Today workspaces,
Task create/edit and nested pickers, Calendar, Analytics, Focus Plans, Life Browse/Edit/Pinned/Graph,
Reader and Editor, Life interchange previews, Narrative Reader/Studio and its visual worlds,
Settings, Search, keyboard help, backup, and restore confirmation.

`capture-audit.json` is the machine-readable record for the current light-theme walk. It measured a
1536 × 794 WebView at 125% Windows scaling across 53 states, with zero semantic collisions, zero
document overflow, and zero viewport overflow. No destructive import or restore action was
confirmed while producing these screenshots.

Every PNG is a current maximized light-theme capture; alternate theme copies are intentionally not
included in this delivery.

The directory name intentionally follows the requested spelling: `screenshoots`.
