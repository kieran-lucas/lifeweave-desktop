# 07 — Visual Reference Authority

The six PNGs are visual evidence, not product-capability specifications.

## Global rule

**Source/canonical manifest decides what exists. References decide visual character only where approved.**

Never implement a control or data concept because it appears in an image.

| File | Authority | Use | Explicit exclusions |
|---|---|---|---|
| `references/01-today-approved-direction.png` | APPROVED VISUAL DIRECTION | shell proportion, Today hierarchy, row density, selected split, inspector material, blue/near-white character | do not copy invented microcopy/data |
| `references/02-calendar-approved-direction.png` | APPROVED VISUAL DIRECTION | Calendar prominence, month grid as hero, typography, spacing, selected-day treatment, restrained controls | **no Day Details inspector, event-chip system, New Plan, or invented Calendar data** |
| `references/03-analytics-direction.png` | DIRECTIONAL | hierarchy, typography, calm data density, visual quality | no invented KPI/data/chart capability; canonical Analytics projection wins |
| `references/04-focus-plans-direction.png` | DIRECTIONAL | master/detail seriousness, spacing, hierarchy | no owner/collaboration capability |
| `references/05-life-direction.png` | DIRECTIONAL | atlas/spatial identity, low-chrome canvas character | source Life Browse/Edit/Graph topology wins |
| `references/06-reader-direction.png` | DIRECTIONAL | editorial measure, typography, quiet chrome | no invented Reader utilities |

## What may be learned from a reference

- hierarchy;
- density;
- whitespace rhythm;
- typography character;
- surface/material restraint;
- blue identity;
- selected/focus visual distinction;
- craftsmanship target;
- relative composition.

## What may not be inferred

- routes;
- controls;
- backend data;
- features;
- actions;
- inspector existence;
- filters;
- collaboration/profile identity;
- domain semantics.

## Attachment note for Codex CLI

Repository PNGs are not automatically model-visible image inputs merely because their paths exist.
The launch guide provides an optional `-i/--image` preflight attachment flow. If images are not attached/visually inspectable in the current session, the text specifications remain sufficient execution authority; do not fabricate what an unseen image contains.
