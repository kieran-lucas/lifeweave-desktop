## Implementation

Milestones is immediately below Today, followed by Calendar, Plans, Life System and separated
Settings. Existing global accelerators retain their assignments. The existing history envelope
supports the new destination, including reload and Back. Today remains the default destination.

React owns ephemeral selection/dialog state. TanStack Query holds the asynchronous projection.
Three centralized typed commands delegate to Rust domain validation and the existing SQLite
worker. Schema 35 appends one independent table, with checked pin/revision fields, stable UUID,
local calendar date, plain Unicode text, UTC creation/update instants and recoverable deletion.
Writes are transactional and revision checked. Duplicate UUID inserts never overwrite data.
Deleted milestones retain all their fields and have a durable Restore path. Startup, backup
verification/compatibility and restore share the new schema authority. Earlier migrations are
unchanged; TypeScript contracts and scoped command permissions are generated by existing tools.
There are no new dependencies, remote resources, Tasks, Calendar events or Plan associations.

The page uses the actual Today masthead CSS, wide PageFrame, Lexend typography, visual contract,
Fluent flag, shared buttons, EmptyState and dialog/focus primitives. The current application has
one runtime light theme; Milestones preserves that behavior under a dark system preference.

Every day is eight CSS pixels. UTC-noon date objects are used only through the existing calendar
utility for arithmetic/formatting; milestone dates stay date-only strings. Month lengths, leap
days and year/DST boundaries therefore retain equal day distances. The initial range is month
-2 through +10, with Today near 30% of the viewport. The existing local-date rollover hook updates
the indicator/countdown at midnight and on focus/visibility recovery, without recentering.

One native overflow canvas contains the baseline, elapsed segment, month labels, ticks, markers,
connectors and callouts. Trackpad/wheel and touch scrolling remain native; empty-space mouse
dragging changes only scrollLeft; only Shift-wheel is converted. No raw scroll-driven React state,
custom inertia, snapping, per-marker measurement or automatic edge loading exists. Explicit month,
date, Find or Today controls navigate programmatically. Prepends first compensate scrollLeft by
the exact added day width; distant explicit jumps replace the bounded range. Resize/data refresh
never recenter. Reduced Motion uses instant scrolling and removes the detail entrance transform.

Labels have fixed 200×44 rectangles and are greedily packed into nonintersecting 56px lanes. Every
milestone retains its own callout, including duplicate dates. Very dense lanes scroll vertically
inside the timeline with a visible instruction. Same-day markers have an accessible count; the
small printed count appears when neighboring marker counts have enough room. Long titles remain
complete in accessible names and details. Find reaches unpinned and out-of-window moments.

The detail area reserves 280px and scrolls internally for long content. Its DOM remains stable
when switching same-day milestones so keyboard focus is retained. Creation/editing supports
validation, retained failed drafts, pending guards, Escape, trapping and deterministic focus
restoration, including when an empty-state opener disappears. Delete is confirmed; Restore moves
focus to the restored detail heading. Selection is also announced through a concise status region.
